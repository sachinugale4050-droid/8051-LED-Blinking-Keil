# 8051 Delay Loop Practice

## Project Overview
This project demonstrates a software delay function and Port 2 output using an 8051 microcontroller programmed in Embedded C.

## Tools Used
- Keil µVision
- Proteus Design Suite
- 8051 AT89C51 Microcontroller

## Concepts Practiced
- C functions and parameters
- Nested for loops
- Software delay loops
- Port 2 output
- Compiling the program and generating a HEX file

## Project Status
Learning and simulation practice. Successful hardware testing has not been confirmed.
